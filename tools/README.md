# 학년부 도구 (고양외고 25기 1학년부 판)

앱 밖에서 학년부 담당 교사가 쓰는 도구 두 개. 앱과 같은 저장소에 두어 앱의 파일 구조(`schema.sql`),
기본 점검 목록, 학번 해석 규칙을 그대로 쓴다. Node 24 이상, 저장소에서 `npm ci`를 한 번 해 둔 상태에서 돌린다.

**실제 학생 이름이 든 결과물은 저장소 밖에 만든다.** 도구가 저장소 안 결과 폴더를 거부한다(가짜 자료 시험의 `--test`만 예외).
화면에는 개수만 나오고 이름·문장은 나오지 않는다.

## 1. 학년 일괄 세팅 — 반별 프로젝트 파일 만들기

```
node tools/grade-setup/grade-setup.mjs --roster <학년 명렬표.xlsx> --config <설정.json> --out <결과 폴더> [--classes 1,3]
```

- 명렬표: 학번·이름 열 또는 학년·반·번호·이름 열(머리글로 찾음, 위에 제목 줄이 있어도 됨). 같은 번호가 두 번 있거나
  이름이 빈 행이 있으면 아무 파일도 만들지 않고 행 번호를 알려 준다.
- 설정: `grade-setup/setup.example.json` 참고. 영역마다 활동을 적어도 하나 둔다(활동 없는 영역은 앱에서 쓸 수 없다).
  `scanList`로 금지어 스캔 목록 JSON의 규칙을 점검 묶음으로 넣을 수 있다(단어·변형만, 정규식 패턴은 앱이 지원하지 않아 뺀다).
- 결과: 반마다 `.db` 하나. 반 전원, 영역·활동, 영역마다 전원 배정, 앱 기본 유의어·치환 규칙, 학교 공통 점검 묶음. 기록은 빈칸, 암호 없음.
  만든 뒤 다시 열어 검사하고, 이미 있는 파일은 덮어쓰지 않는다.
- 앱은 한 영역 안의 활동을 **이름 순서**로 늘어놓고 그 순서로 합쳐 내보낸다. 순서가 중요하면 활동 이름 앞에 번호를 붙인다.

## 2. 수합파일 반별 분할

```
node tools/collect-split/collect-split.mjs --input <수합파일.xlsx> --roster <학년 명렬표.xlsx> --out <결과 폴더> [--map <대응.json>] [--prefix <이름>]
```

- 수합파일 한 행 = 학번 | 이름 | 행사명 | 지도교사 | 기재내용 (머리글로 찾음).
- 결과: 반마다 `<prefix>_1-3.xlsx`(앱 가져오기 "행 단위 활동 형식" 그대로)와 `<prefix>_확인목록.xlsx`.
- 이름이 명렬표와 다른 행, 명렬표에 없는 학번, 같은 학생·활동이 내용이 달라 두 번 나온 행은 반 파일에 넣지 않고 확인목록에 올린다.
- `--map`: `{"행사명": "앱 활동명"}`. 순서를 맞추려면 `"03 학급자치회의"`처럼 번호 붙인 이름으로 대응시킨다.
  같은 활동을 다시 가져올 때(수정본) 활동명이 같아야 앱이 같은 활동으로 맞춘다.

담임이 앱에서 가져오면, 지난번 가져온 뒤 고친 칸은 기본으로 덮어쓰지 않는다(체크 해제, 세 판 비교).

## 시험

`npm run test:ts`가 `tools/test/`도 함께 돈다(가짜 자료, 임시 폴더). 도구나 `schema.sql`을 바꾸면
`node tools/test/make-rust-fixture.mjs`로 Rust 시험용 고정 파일을 다시 만든다(`src-tauri/src/tests/grade_setup_fixture_tests.rs`가 앱의 실제 열기 경로로 연다).
