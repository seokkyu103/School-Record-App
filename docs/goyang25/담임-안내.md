# 담임 선생님 안내 — 고양외고 25기 1학년부 판

학년부가 우리 반 학생 명단, 영역 4개(자율·자치 1500 / 동아리 1500 / 진로 1500 / 행발 900바이트), 학교 공통 점검어를 넣어 둔 파일(`2026_1-○_생기부.db`)을 드립니다. 이 파일을 열어 쓰시면 됩니다.

## 1. 처음 한 번만

1. 받은 `.db` 파일을 **내 PC의 폴더**(예: 문서)에 둡니다. USB·공유 폴더·클라우드 동기화 폴더에서 바로 열지 않습니다.
2. 프로그램을 실행하고 파일을 엽니다.
3. 왼쪽 아래 **설정(Settings)** → **데이터 암호화** → **암호화 활성화** → 비밀번호(4자 이상)를 두 번 입력합니다.
   - 비밀번호를 잊으면 **어떤 방법으로도** 복구할 수 없습니다. 따로 적어 두세요.
4. 파일이 있는 폴더를 엽니다. 이름이 `2026_1-○_생기부.(날짜-시각).db.backup`인 파일 가운데 **암호화를 켜기 전에 생긴 것**을 지웁니다.
   - 프로그램은 파일을 열 때마다 백업을 하나씩 만듭니다. 암호화 전 백업에는 학생 이름과 내용이 그대로 보입니다.
   - 휴지통도 비웁니다.

## 2. 평소에

- 작업이 끝나면 프로그램을 닫습니다. 자리를 비울 때 화면을 잠급니다(Windows 키 + L).
- 백업 파일은 열 때마다 쌓입니다. 오래된 것은 가끔 지워도 됩니다(암호화 뒤 백업은 비밀번호가 있어야 열립니다).
- 학생 기록 파일을 메신저·메일로 주고받지 않습니다.

## 3. 수합파일 가져오기

행사 담당 선생님이나 학년부에게서 받은 엑셀을 가져올 때 씁니다.

1. 왼쪽 **가져오기(Import)** → Step 1에서 파일 선택
2. Step 2에서 **A 타입(행 단위 활동 형식)** 선택
3. Step 3 열 매핑은 대개 자동으로 맞춰집니다. 학년·반·번호·이름·활동명·활동내용이 맞는지만 봅니다.
4. Step 4에서 처음 보는 활동은 **새로 만들 활동을 넣을 영역**을 고릅니다(예: 학급자치회의 → 자율·자치).
   - 이미 있는 활동(예: 수요독서토론)이 처음 보는 활동으로 뜨면, 파일의 활동명이 앱의 활동 이름과 글자·띄어쓰기까지 같은지 확인합니다. 다르면 칸이 따로 하나 더 생깁니다.
5. Step 5 변경사항 확인
   - **수합본만 바뀜**: 선생님이 손대지 않은 칸입니다. 기본으로 체크되어 있습니다.
   - **가져온 뒤 고침**: 선생님이 고친 칸입니다. 기본으로 체크하지 않습니다. 체크하면 고친 글이 수합본으로 바뀝니다.
   - 빨간 상자(이름이 다른 학생)가 나오면 멈추고 학년부에 알려 주세요.
6. Step 6에서 실행합니다. 덮어쓴 칸도 이전 글이 기록 이력에 남습니다.

## 4. 학기 중에 공통 활동 추가하기 (1분)

학년부가 공통 활동을 새로 알려 주면, 수합파일 가져오기(3번)를 쓰면 저절로 생깁니다. 직접 만들 때는 다음과 같이 합니다.

1. 왼쪽 **활동(Activity)** → 오른쪽 위 **활동 추가**
2. **활동 이름**은 학년부가 알려 준 이름을 **글자 그대로**(앞 번호 포함, 예: `03 학급자치회의`) 넣습니다. 이름이 반마다 다르면 나중에 학년 단위로 모을 때 따로 묶입니다. 활동은 이름순으로 정렬되므로 앞 번호가 순서를 정합니다.
3. **포함할 영역**에서 영역 하나를 누르고 **추가**
4. 우리 반 학생은 모두 그 영역에 배정되어 있으므로 바로 **생기부 작성(Write)** 화면에 칸이 생깁니다.

## 5. 학생 간 중복 확인

왼쪽 **중복 확인(Duplicate)** → 영역과 비교 단위를 고르고 **중복 확인**을 누릅니다.

- **완전 일치·유사·같은 문장**으로 나눠 학생 쌍을 보여 줍니다. 쌍을 누르면 두 글이 나란히 나오고 겹친 문장이 칠해집니다.
- 여러 학생에게 같은 행사 소개 문장(5명 이상)은 **공통 문구**로 따로 모아 기본으로 경고에서 뺍니다.
- 결과는 확인할 후보입니다. 같은 행사라 비슷할 수밖에 없는 경우도 있으니 직접 읽고 판단해 주세요.
